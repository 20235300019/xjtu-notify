关于组建中国青年志愿者西安交通大学第29届研究生支教团的通知

信息来源： 发布日期: 2026-08-29 浏览次数:

           根据全国大学生志愿服务西部计划项目管理办公室（以下简称“全国项目办”）《关于组建第29届中国青年志愿者研究生支教团（2027—2028年度）有关工作的通知》（全国项目办发〔2026〕4号）、《关于进一步加强中国青年志愿者研究生支教团工作的意见》（中青办联发〔2026〕1号）等有关文件要求，结合学校推免工作统一安排，现启动西安交通大学第29届研究生支教团（2027—2028年度）招募及组建工作，有关事项通知如下。

一、招募原则

按照全国项目办有关要求，坚持“公开招募、自愿报名、择优选拔”的原则，招募一批具备推荐免试攻读硕士学位研究生条件的优秀应届本科毕业生和在读研究生，作为青年志愿者到中西部地区县级及以下中小学校开展为期一年（2027年8月至2028年7月）的基础教育或职业教育教学志愿服务工作。招募仅限于本校，纳入全校年度研究生招生总计划，研究生支教团招募工作整体纳入学校推免工作统一管理；其中，研究生阶段即将攻读理工科专业的学生择优纳入“国优计划”培养。

二、报名条件

（一）报名者应同时符合以下基本条件：

1. 符合我校关于推荐免试攻读硕士学位研究生条件的2027届本科毕业生或在读研究生，学业综合成绩基本要求须与所在学科专业普通类推免生综合成绩基本要求保持一致；

2. 拥护中国共产党领导，热爱祖国、热爱人民、热爱社会主义，理想信念坚定，思想政治素质好，坚定拥护“两个确立”，牢固树立“四个意识”，坚定“四个自信”，坚决做到“两个维护”；身心健康，遵纪守法，无任何违法违纪受处分记录，能胜任西部地区基础教育或职业教育志愿服务工作；

3. 有独立调研和解决问题的能力，较强的组织能力、语言表达能力和团队协作精神；

4. 中共党员（含预备党员）或共青团员；

5. 诚实守信，学风端正，品行优良。凡有考试作弊、剽窃他人学术成果或违纪违法等不良记录者，不得入选；

6. 入选名单公示后，候选人不得因获得其他免试推荐研究生、就业、出国（境）等原因放弃支教资格。

（二）符合基本条件，具备以下条件者优先：

1. 中共党员（含预备党员），在所在党组织内起模范带头作用，具有良好的群众基础；

2. 乐于奉献，在校期间有较突出的志愿服务经历，或曾担任校、院（书院）两级主要学生干部；

3. 获省级及以上荣誉称号或科创竞赛、文体竞赛奖励；

4. 获得中小学教师资格证或已报名参加2026年下半年中小学教师资格考试；

5. 在读研究生，能妥善处理学习科研与工作间的关系。

三、选拔流程

1. 宣传动员。项目办综合运用各类方式，重点面向2027届本科毕业生和在读研究生进行招募宣传动员；面向全体在校学生尤其是低年级学生，开展日常宣传教育。

2. 个人报名。申报人对照清单准备有关报名材料，在9月11日18:00前向校团委提交。纸质版提交至团委1号办公室（宪梓堂西侧院内），电子版材料同步发送至指定邮箱，邮件主题为“姓名+29届支教团报名”。申请人提交材料必须真实有效，凡发现弄虚作假者，一律取消申请资格，并通报其所在书院、学院。材料清单如下：

3. 院系推荐。申报人报名材料应由学院、书院党组织审核，各学院、书院应结合学生思想政治表现、学业成绩、志愿服务经历和综合能力等进行审核把关，并在报名登记表上盖章。

4. 资格审查与综合考察。研究生支教团招募工作小组对报名学生进行资格审查、初步遴选，确定入围候选人并统一组织差额面试。面试考官由招募工作领导小组成员单位有关人员组成，集中面试全程记录，相关资料长期留存。具体形式、时间、地点另行通知。

5. 体检及公示。招募工作小组根据综合考察结果，确定拟入选名单（含递补学生），报学校推免生遴选工作领导小组、研究生支教团招募工作领导小组和研究生招生工作领导小组审核后按要求在团委网站公示，公示期不少于7个工作日。同时，组织入选者统一体检（含递补学生），体检按西部计划志愿者体检项目和标准执行（附件2、3）。

6. 系统上报与签约。公示期结束后，校团委指导入选志愿者登录西部计划官网，在西部计划信息管理系统填报相关信息并完成审核。审核通过者，方为西安交通大学第29届研究生支教团正式成员。入选学生与学校签订《招募协议书》，并由项目办协同教务部门在教育部推免服务系统中完成相关信息录入和录取确认。

根据全国项目办通知和相关规定，研究生支教团招募工作纳入学校整体推免工作统一管理，支教团选拔与学校推免工作时间节点同步推进。报名支教团的同学须同步参与学校推免工作前序流程，与其他推免资格申请学生同步按学校有关工作要求，完成学校研究生报考服务系统报名、学业成绩核算、综合测评排名核对、复试（或面试）等全部前序环节。未按规定完成或中途放弃者，由个人承担后果。

四、条件保障

1. 服务期间，应届本科毕业生保留研究生入学资格一年，在读研究生保留学籍，人事档案挂靠在西安交通大学，党、团组织关系临时转到志愿服务所在地的党、团组织。

2. 按照大学生志愿服务西部计划有关规定，研究生支教团志愿者享受服务期为一年的有关政策。志愿服务期满考核合格的，计算服务期及工龄，并在服务证书及服务鉴定表中体现。

3. 服务期间，工作生活补贴、社会保险、商业保险等服务保障，执行当年度西部计划实施方案有关规定；县级项目办协调服务单位为支教团志愿者提供食宿便利等生活保障。各服务地为每名研究生支教团成员购买重大疾病、人身意外伤害等商业保险，覆盖支教全程及到达、离开支教地的前后三天。

4. 学校向参加支教团的志愿者提供每年两次家庭所在地往返支教服务地的交通费用（赴西藏、新疆等地区者可乘坐飞机，赴其他服务地以火车硬卧为主）。

五、后续管理

1. 志愿者必须遵守《中国青年志愿者研究生支教团管理细则》与《大学生志愿服务西部计划志愿者管理办法》等文件要求，服从全国项目办、服务地项目办、服务学校和西安交通大学项目办管理。第29届研究生支教团组建后必须全员报名参加中小学教师资格证考试并通过考试。如有不当言行且造成不良影响，将视情节轻重给予相应处分。

2. 服务结束后，志愿者须填写《志愿服务鉴定表》及个人服务总结，经服务地项目办审定。支教团成员的考核工作由全国项目办、地方项目办和我校项目办共同负责，学生返校入学后一个月内公布考核结果，分优秀、合格、不合格三类，鉴定表和考核结果进入志愿者个人档案。志愿者退出研究生支教团或考核不合格的，按有关规定处理，并取消其免试攻读研究生资格。

3. 研究生支教团成员派出前须接受校团委组织的思想政治、教学技能、挂职锻炼、社会工作、志愿服务、师德师风等岗前培训（纳入我校“青马工程”研究生支教团专项培养方案），累计完成不少于100学时理论学习和不少于两周的教学试讲、实习见习。服务期满回校后，优先推荐到团学组织兼职工作。
